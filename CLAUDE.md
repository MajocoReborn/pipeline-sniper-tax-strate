# Working agreements

## Language

- **Talk to the owner in Dutch**: chat replies, questions, summaries and status updates.
- **Write everything that goes into the repository or onto GitHub in English**: code,
  comments, docs, commit messages, branch names, pull request titles and descriptions, review
  replies and issue comments.

## Where to start

Read [`docs/HANDOFF.md`](docs/HANDOFF.md) first: current state, commands, pitfalls and devnet
details. The design is in [`docs/PLAN.md`](docs/PLAN.md), the security review in
[`docs/SECURITY-REVIEW.md`](docs/SECURITY-REVIEW.md).
